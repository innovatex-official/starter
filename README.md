# InnovateX Starter

A simple, lightweight React starter template with **React 18**, **Vite**, **TypeScript**, and **Tailwind CSS**.

Used for learning Git workflows, component-driven development, and frontend fundamentals.

---

## Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/innovatex-official/starter.git

# 2. Navigate to the project directory
cd starter

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

The application runs locally at `http://localhost:3000`.

---

## Tech Stack

- **[React 18](https://react.dev/)** — UI library
- **[Vite 6](https://vitejs.dev/)** — Development server and bundler
- **[TypeScript](https://www.typescriptlang.org/)** — Static typing
- **[Tailwind CSS](https://tailwindcss.com/)** — Utility CSS styling

---

## Project Structure

```text
starter/
├── public/              # Brand assets and favicon
├── index.html           # HTML entry point
├── package.json         # Dependencies and scripts
├── vite.config.ts       # Vite configuration
├── tsconfig.json        # TypeScript configuration
├── tailwind.config.js   # Tailwind CSS configuration
├── postcss.config.js    # PostCSS configuration
└── src/
    ├── main.tsx         # Application entry
    ├── App.tsx          # Main component
    └── index.css        # Tailwind directives and CSS variables
```

---

## Available Scripts

- `npm run dev` — Starts local development server.
- `npm run build` — Compiles TypeScript and builds production assets into `dist/`.
- `npm run preview` — Previews the production build locally.
